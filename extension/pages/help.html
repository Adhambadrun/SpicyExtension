SpicyExtension

Local result capture

1.0.0
LOCAL ONLY · NO AUTOMATIC UPLOADS

A safe, reviewable way to record the real structure of one flight result.

This tool is a capture step for the planned SpicyExtension flight assistant. It is not the completed assistant, does not perform flight searches, and does not supply inventory, pricing or booking services.

INPUT / SELECT A RESULT

Capture a result

  1. Open the connected site in your usual Chrome profile. Sign in on the website normally and run a search you are authorized to make.
  2. After installing or reloading this extension, reload that site tab. Pin the extension from Chrome’s Extensions menu if helpful.
  3. On the /flights or /search page, click the toolbar icon and Open capture panel, then Select a result area.
  4. Move over one flight-result card. Check the outline. Use ↑ / Larger and ↓ / Smaller to adjust, then click or press Enter. Escape cancels. The selection layer prevents that click from activating the page’s own controls.
  5. Review the plain JSON. Remove any names, booking references, account information or other private text. Check that flight fields, route, dates, cabins and fare structure remain useful.
  6. Confirm that you reviewed it, then Download JSON. Copy JSON is available if Chrome permits clipboard access. The tool uploads nothing; you choose whether and where to share the file.
  7. For a second sample, expand the itinerary on the site, select its details area, choose Expanded itinerary details, and repeat. Closing the tool clears its in-memory capture, not files you already downloaded.

Never add cookies, authorization headers, passwords, API keys, account data or an unsanitized HAR. Existing login stays with Chrome and the website.

SITE / ONE EXACT ORIGIN

What the extension reads

Only after an explicit capture action: the active tab’s URL to check the exact allowed origin and route, the geometry of the area you point to, and the visible text/structure of the selected subtree. URL queries and fragments are not exported. It never reads cookie APIs, local/session storage, password or other form-control values, or page JavaScript state.

A dormant content-script listener is installed on the supported search routes so the toolbar can open the capture panel. It does not capture the page on load. The single host permission is https://agentsearch.vercel.app/*; there is no access to mail, other sites, or other browser profiles.

OUTPUT / REVIEW & REDACT

What gets removed — and what may remain

Scripts, styles, embedded frames/media, hidden subtrees, form controls, links’ destinations, resource URLs, event handlers, IDs and arbitrary data attributes are omitted. A small allowlist preserves classes, roles, labels and test IDs so the flight-result structure can be studied. Recognizable email addresses, URLs and common credential patterns in text are replaced.

This is not complete anonymization. Names, booking references, unusual tokens, phone numbers or personal information in visible text/allowed labels may remain. Offscreen content is not necessarily hidden; the tool is not a visual screenshot or full visibility audit. You must review the selected capture before export and again before sharing it.

Shadow-root content is not included. Large/deep selections are rejected rather than silently truncated. Open details on the site before capturing them. The output is a diagnostic HTML/text snapshot inside JSON, not a flight API response or a verified normalized flight model.

OUTPUT / LOCAL ONLY

No uploads, tracking or persistence

The extension has no network client, backend, analytics, telemetry or automatic upload. It stores no capture in Chrome storage or a database. Captures remain in the panel’s memory until cleared, closed, or the page navigates. Export and clipboard operations require an explicit, reviewed user action. Downloaded files and clipboard contents are under your control; the extension does not erase them afterward.

The connected website still operates normally and may make its own network requests. This extension does not modify its login, replay authenticated requests or bypass its access controls.

HELP / RECOVERY

Troubleshooting

  • Open capture panel is disabled: activate a signed-in /flights or /search tab on the connected site. Login/account pages are deliberately excluded.
  • Page did not acknowledge: reload the site tab after extension installation/reload. Chrome does not automatically inject the new script into already-open pages.
  • Only an airline name was captured: use Larger area until the intended card is included. Check the JSON; do not select the whole application.
  • No visible text: select the enclosing flight card rather than a logo, icon, hidden element or form field.
  • Export is disabled: review the current JSON and check the confirmation. Every text or area change requires a new review.
  • Clipboard blocked: use Download JSON and check Chrome’s download list.
  • Panel covers the result: drag the header, or focus the header’s move button and use arrow keys.
