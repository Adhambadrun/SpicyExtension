Support

SpicyExtension 1.0.0 · questions, problems and how to reach a human

Need help or found a bug? Open an issue at github.com/Adhambadrun/SpicyExtension/issues. Please include your Chrome version, the extension version, and what you expected to happen. Never paste cookies, authorization headers, passwords, API keys, account data or an unsanitized HAR file into an issue — none of that is needed to diagnose a problem here.

Installing

  1. Download the packaged build from the repository's release/ folder and extract it, or build it yourself with npm ci and npm run build.
  2. Open chrome://extensions and turn on Developer mode.
  3. Choose Load unpacked and select the folder that contains manifest.json (when building from source, that is dist/spicyextension).
  4. Use the same Chrome profile you normally sign in with. The extension cannot move a login between profiles or devices.
  5. Reload the site tab after installing or reloading the extension. Chrome does not inject a newly installed content script into pages that are already open.

Capturing a result

  1. Sign in on the connected site yourself and open a results page.
  2. Click the toolbar icon, then Open capture panel.
  3. Choose Select a result area and move the pointer over one card. Check the outline and the size readout.
  4. Adjust with Larger / Smaller or the ↑ / ↓ keys. Click or press Enter to capture; Esc cancels.
  5. Read the JSON and remove anything private. Tick the review confirmation, then Download JSON.
  6. To capture itinerary details, expand them on the site first, select that area, and set the capture type to Expanded itinerary details.

Troubleshooting

"Open capture panel" is greyed out

The active tab has to be a supported results page on the connected site. Sign-in and account pages are deliberately excluded. Switch to the results tab and reopen the popup.

Nothing happens, or the page does not acknowledge the panel

Reload the site tab. After an extension is installed or reloaded, Chrome does not place the new content script into tabs that were already open.

Only a small fragment was captured

Press Larger (or ↑) until the outline covers the whole card, then capture again. Pointing at a table cell selects that cell; widening moves the selection to its container.

The capture has no visible text

Select the enclosing card rather than a logo, icon, hidden element or form field. Images and form controls are intentionally excluded.

The export buttons stay disabled

Tick the review confirmation. Any edit to the JSON, a change of capture type, or resizing the selection clears it again, because each of those produces something new for you to check. If the status line reports invalid JSON, correct it or press Reset redactions.

Copy JSON does not work

Chrome may withhold clipboard access in some contexts. Use Download JSON instead and look in your downloads list.

The panel is covering the card I want

Drag the panel by its header, or focus the move handle and use the arrow keys. The panel always stays within the viewport.

Clicking during selection activated something on the page

It should not — the selection layer intercepts the click. If you can reproduce this, please report it with the steps you took; that would be a genuine bug.

Frequently asked

Does it upload my captures anywhere?

No. The extension contains no network client at all, and its pages are locked down with connect-src 'none'. Files reach other people only if you send them yourself. See the privacy policy.

Can it see my password or my login?

No. It has no cookies permission, never reads form values, and never copies authentication. Signing in stays entirely between you, Chrome and the website.

Is my capture fully anonymous?

No, and it is important not to assume so. Automatic redaction handles email addresses, URLs and common credential patterns, but names, booking references and other personal text can remain. Read the JSON before you export it, and again before you share it.

Why does it only work on one site?

Because it only asks for one host permission. Narrow access is the point: the extension cannot run anywhere it has not declared, and you can confirm that in manifest.json.

Does it search, price or book flights?

No. Version 1.0.0 is a local capture tool only. It reads no API, replays no authenticated request, and supplies no inventory or pricing.

How do I remove it?

Open chrome://extensions and choose Remove. Since nothing is stored, there is no leftover data — only the files you chose to download, which you can delete as usual.

Reporting a security issue

Please report suspected security problems through the issue tracker, with enough detail to reproduce the behaviour. Since the extension is open source, a pull request is welcome too.
